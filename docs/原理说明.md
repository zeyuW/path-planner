# 路径规划系统原理说明

## 1. 系统概述

本系统用于解决「板类壁板表面自动扫描路径规划」问题：给定一个零件的 STEP 模型，自动完成三步工作——

1. **表面提取（选面）**：从整件中自动识别出需要扫描的待测表面；
2. **视点规划**：在该表面上布置相机测量视点（位置 + 朝向），使其覆盖整个表面；
3. **路径规划**：把视点排成一个合理的访问顺序，输出可供机械臂/测量仪执行的扫描路径。

最终交付的核心结果是 `Path_base_world.txt`（世界坐标系下的扫描路径）。相机标定、障碍物识别、TCP 转换、机械臂可达性与轨迹插补、碰撞检测等属于外部环节，**不在本程序范围内**。

---

## 2. 整体流程

```
STEP 文件
   │
   ▼
┌─────────────────┐      ┌──────────────────┐      ┌─────────────────┐
│ 阶段一：表面提取  │ ───▶ │ 阶段二：视点规划   │ ───▶ │ 阶段三：路径规划  │
│ （自动选面）     │      │ （矩形覆盖+补点）  │      │ （分组+蚁群排序） │
└─────────────────┘      └──────────────────┘      └─────────────────┘
   │                          │                          │
   ▼                          ▼                          ▼
extraction/             viewpoints/                 path/
选面结果                 视点列表                    扫描路径
```

三个阶段之间直接传递内存数据，不再像旧版那样通过中间 txt 文件接力。最终结果统一写入 `out/<零件名>_<时间戳>/`。

---

## 3. 阶段一：表面提取（自动选面）

### 3.1 输入与离散

- 输入为 STEP 文件，用 OCCT（OpenCASCADE）内核读取。
- 将 CAD 曲面离散为三角网格。离散精度由两个误差参数控制：`linear_deflection_mm`（线性偏差，越小越贴合曲面）和 `angular_deflection_deg`（角度偏差，越小弧面越细）。

### 3.2 自动选面原理

程序无需人工指定要扫描哪个面，而是自动识别「面积最大的连续宽面」。方法如下：

1. **找厚度轴**：对整件所有三角面片做面积加权 PCA，主方向即为零件的厚度轴。
2. **找宽面**：在厚度轴的正、反两侧，找出法向与厚度轴偏差不超过 `normal_tolerance_deg`（25°）的面，作为候选面。
3. **合并邻接面**：沿共享 CAD 边，把方向相近的相邻面合并起来（允许夹角 `adjacency_angle_deg`，15°），得到若干连通区域。
4. **选最大区域**：取面积最大的连续区域作为待测表面。两侧面积几乎相同时，按 CAD 面顺序选一侧，并在结果里标记 `side_ambiguous`（歧义）。

### 3.3 建立局部坐标系

选面后建立一个局部坐标系，便于后续在二维平面上铺矩形：

- **X 轴**：沿表面长边（PCA 主方向）；
- **Y 轴**：沿表面宽度；
- **Z 轴**：沿厚度方向（指向表面平均外法向的反方向）。

于是待测表面近似「躺」在 XY 平面内。局部坐标系到原始 STEP（世界）坐标系的变换矩阵 `local_to_world` 记录在 `selection.json` 中。

### 3.4 边界外扩

为了让相机视场能盖住表面边缘，把**外轮廓向外扩一圈**（`boundary_expansion_mm` = 50mm），得到「覆盖边界」`scan_area`。

### 3.5 本阶段输出

| 文件                         | 说明                                                          |
| ---------------------------- | ------------------------------------------------------------- |
| `selection.json`             | 选面报告：选中面编号、面积、孔数、`local_to_world` 变换矩阵等 |
| `target_surface.step`        | 提取出的 CAD 面（原模型坐标），可在 CAD 软件核对              |
| `target_surface_world.obj`   | 原模型坐标下的三角网格                                        |
| `surface_boundary.txt`       | 真实表面边界（未外扩）                                        |
| `target_surface_preview.png` | 选面二维预览图（含外扩覆盖边界）                              |

## 4. 阶段二：视点规划

### 4.1 矩形覆盖（生成二维视点）

把相机在最佳工作距离下的视场近似为一个矩形，尺寸由 `rectangle_width_mm × rectangle_height_mm`（324×297mm）定义。用贪心算法在「外扩后的覆盖边界」上铺矩形：

- **候选**：把区域划分成网格（间距 `candidate_grid_size_mm` = 250mm），每个网格点和区域顶点作为矩形中心候选；每个中心再尝试多个旋转角度（步长 `angle_step_deg` = 45°）。
- **贪心**：每轮挑选「新增覆盖面积最大」的矩形，直到覆盖完或达到 `max_cover_iterations`（500）。
- **缩放**：矩形实际按 `scale_factor`（0.9）缩小后再参与覆盖，让相邻矩形之间有重叠，避免边界漏缝。

铺完得到的矩形中心，就是「二维视点」。

### 4.2 二维视点 → 三维视点

每个矩形覆盖了一批三角面片，据此把二维视点映射到三维空间：

1. 用这些三角面片的顶点**拟合一个平面**；
2. 把矩形中心沿局部 Z 轴投影到这个平面上，得到表面上的点；
3. 计算这些面片的**平均法向**，沿其反方向（朝表面外）偏移 `viewpoint_offset_mm`（300mm，即相机最佳工作距离），得到三维视点位置；
4. 视点朝向 = 平均法向的反方向（相机正对表面）。

若某个矩形覆盖的三角面片数少于 `triangle_threshold`（30），则丢弃该矩形，不生成视点。

### 4.3 可见性判定

对每个视点生成一个**视锥（四棱台）**：近端为视点处的视场矩形，远端在 555mm 处按比例放大，有效深度范围约 45~555mm。一个三角面片被判为「已覆盖」，需同时满足：

1. 三个顶点都落在该视锥内部；
2. **入射光线与面片法向的夹角**不超过可接受范围（`visibility_angle_threshold_deg` = 120°，即偏离正对不超过约 60°）。太斜的面片判为不可见。

所有视点判定完后，仍未覆盖的面片就是「残余面片」。

### 4.4 补点与迭代

对残余面片做 **DBSCAN 聚类**（邻域半径 `dbscan_eps_mm` = 50mm，最少样本 `dbscan_min_samples` = 50），每个有效簇生成一个矩形，再走一遍「映射 → 可见性判定」。如此重复，最多 `max_refinement_cycles`轮。

如果残余面片太零散、凑不成有效簇，则无法再补视点，停止原因记为 `no_candidates`——这通常意味着覆盖率会停在孔洞边缘、边界缝隙等残余小面片上（这是正常现象，不是报错）。

### 4.5 本阶段输出

| 文件                   | 说明                                              |
| ---------------------- | ------------------------------------------------- |
| `VP.txt`               | 视点列表，每行 `序号 角度 位置xyz 朝向xyz`        |
| `VP_visualization.obj` | 视点 3D 可视化（表面网格 + 每个视点的朝向三角锥） |
| `planning_report.json` | 覆盖率、停止原因、视点数、剩余面片数等            |

## 5. 阶段三：路径规划

视点本质上是一堆分布在表面上的点，需要把它们串成一条合理的扫描路径。

### 5.1 主轴方向与分组

1. 对所有视点的局部 XY 坐标做 **PCA**，得到它们排布的主方向（长边方向），并确定起点、终点两端。
2. 把所有视点沿主轴方向投影，**每** `group_step_mm`**（500mm）分一组**。分组的目的是：加快求解、避免在壁板上出现往复回环的路径。

### 5.2 组内蚁群排序

对每一组，用**蚁群算法**求组内的最短访问顺序（固定起点和终点）：

- 第一组的起点为离主轴起点最近的点，终点为组内离起点最远的点；
- 后续组的起点为离上一组终点最近的点，终点为组内离起点最远的点。

蚁群算法的关键参数：`ant_count`、`max_iterations`、`alpha`、`beta`、`evaporation_rate`、`pheromone_deposit`、`initial_pheromone`。

### 5.3 拼接与坐标转换

把各组路径首尾相接，得到整体访问顺序：

1. 输出**局部坐标**路径 `Path_base_pannel.txt`；
2. 用 `selection.json` 中的 `local_to_world` 矩阵，把路径点的位置和方向转换到原始 STEP（世界）坐标，得到**最终路径** `Path_base_world.txt`。

### 5.4 本阶段输出

| 文件                     | 说明                                |
| ------------------------ | ----------------------------------- |
| `Path_base_pannel.txt`   | 局部坐标下的扫描路径（访问顺序）    |
| `Path_base_world.txt`    | **最终交付**：世界坐标下的扫描路径  |
| `Path_visualization.png` | 路径顺序可视化图（起点/终点已标注） |

## 6. 关键参数速查

详细注释见 `config.yaml`，这里列出最关键的几个及其影响：

| 参数                                         | 默认值    | 含义                              | 调大/调小的效果                    |
| -------------------------------------------- | --------- | --------------------------------- | ---------------------------------- |
| `step_preprocessing.boundary_expansion_mm`   | 50        | 覆盖边界外扩量                    | 调大更不容易漏边，但视点变多       |
| `step_preprocessing.mesh_size_mm`            | 40        | 三角网格最大边长                  | 调小更精确、更慢                   |
| `viewpoint.rectangle_width_mm` / `height_mm` | 324 / 297 | 相机视场矩形尺寸                  | 等于相机实际视场                   |
| `viewpoint.scale_factor`                     | 0.9       | 覆盖矩形缩放（<1 让相邻矩形重叠） | 调小重叠更多、更不漏、视点更多     |
| `viewpoint.viewpoint_offset_mm`              | 300       | 相机最佳工作距离                  | 等于相机实际工作距离               |
| `viewpoint.visibility_angle_threshold_deg`   | 120       | 可见性夹角阈值                    | 调大更严格（要求更正对）、覆盖更少 |
| `viewpoint.dbscan_min_samples`               | 50        | 补点聚类最少面片数                | 调小补点更积极、覆盖率更高         |
| `viewpoint.max_refinement_cycles`            | 2         | 补点迭代轮数                      | 调大补点更充分                     |
| `path_planning.group_step_mm`                | 500       | 路径分组间距                      | 调小组更多、组更小                 |
| `path_planning.ant_colony.ant_count`         | 20        | 蚁群蚂蚁数量                      | 调大搜索更充分、更慢               |
| `path_planning.ant_colony.max_iterations`    | 200       | 蚁群迭代次数                      | 调大更可能找到短路径、更慢         |

## 7. 坐标系与坐标变换

- **局部坐标系**：X 沿长边、Y 沿宽度、Z 沿厚度。所有选面、视点、局部路径都在此坐标系下计算。
- **世界坐标系**：原始 STEP 模型的坐标。

两者通过 `selection.json` 里的 `local_to_world`（4×4 矩阵，作用于**列向量**）关联：

```
p_world = local_to_world @ [x, y, z, 1]
方向向量只乘矩阵左上角 3×3 部分
```

因此 `VP.txt` 和 `Path_base_pannel.txt` 是局部坐标，`Path_base_world.txt` 是世界坐标，二者配套；换零件重新提取表面后，矩阵和结果会一起变化，重新跑一次程序即可。
